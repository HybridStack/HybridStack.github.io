# Hybrid Stack — Brand Ecosystem

Official brand website and app hub for Hybrid Stack.

## Structure

```
├── index.html          Main brand landing page
├── 404.html            Custom error page
├── sitemap.xml         SEO sitemap
├── manifest.json       PWA manifest
├── sw.js               Service worker
├── assets/
│   ├── css/style.css   Global styles
│   ├── js/main.js      Global scripts
│   └── img/            Brand assets
├── apps/
│   ├── index.html      Apps hub
│   ├── lumina/         Lumina app
│   ├── quickcopy/      QuickCopy app
│   └── alhesab/        ALHESAB app
└── portfolio/
    ├── index.html      Developer portfolio
    └── portfolio-assets/
```
